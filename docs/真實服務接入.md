# 接入真實 AI 服務（Claude + Higgsfield）

| 用途 | 服務 | 預設模型／端點 | 程式 |
| --- | --- | --- | --- |
| 文字（潤飾、腳本） | Claude（官方 `@anthropic-ai/sdk`） | `claude-opus-5-5`，結構化 JSON 輸出，拒絕時自動改用建議的備援模型 | `app/src/ai/claude.js` |
| 圖片（分鏡圖、角色、精緻圖） | Higgsfield Grok Imagine Image 2.0 | `xai/grok-imagine-image-2.0`，16:9，最多 10 張參考圖 | `app/src/ai/higgsfield.js` |
| 分鏡影片 | Higgsfield Seedance 2.0 | `bytedance/seedance-2.0/image-to-video`，精緻圖為首格（需要時也為末格）、原生音訊 | `app/src/ai/higgsfield.js` |
| 語音合成（旁白、選「語音合成」的台詞） | macOS 內建 `say`（預設，免費）；Azure 語音服務（待啟用） | 旁白 Meijia（美佳）、角色依名字固定分配台灣中文語音；Azure 旁白 `zh-TW-HsiaoChenNeural` | `app/src/ai/voice.js` |
| 背景音樂 | 尚未決定（BLOCKED 第 5 項） | 本機佔位音 | `app/src/ai/fake` |

## 設定步驟

1. 在專案根目錄複製 `.env.example` 為 `.env`，填入：
   - `ANTHROPIC_API_KEY`（或改用 `ant auth login`，就不需要這一行）
   - `HF_API_KEY_ID`、`HF_API_KEY_SECRET`（在 [Higgsfield Console](https://console.higgsfield.ai) 建立）
2. 檢查憑證（Claude 送一次很短的請求，約 US$0.01 以下；Higgsfield 只呼叫免費的估價端點）：
   ```bash
   cd app && npm run check:real
   ```
3. 以真實服務啟動（需要 Node.js 22.9 以上）：
   ```bash
   cd app && npm run start:real
   ```

## 行為說明

- **只上傳去識別後的媒體**：送到 Higgsfield 的參考圖只有去識別照片、定裝圖、分鏡圖與精緻圖，先經預簽網址上傳，同一個檔案只上傳一次；金鑰不會送到儲存網址。原圖不會離開本機。
- **費用**：生成前仍以 `app/src/cost/prices.js` 的價格表預估與預留；完成後以實際金額結算（Claude 依用量計算、Higgsfield 依估價端點回傳的美元金額）。失敗或被內容審核拒絕的請求 Higgsfield 不扣點，系統也會退回預留。
- **Seedance 每段至少 4 秒**：短於 4 秒的分鏡會以 4 秒生成，合成時再裁到分鏡秒數（費用以 4 秒計）。
- **影片以 720p 生成**：約 US$0.30／秒，一支 30 秒成品的分鏡影片約 US$12；合成時放大輸出 1920×1080。要改 1080p（約 US$27／支）就設定 `VIDEO_GENERATION_HEIGHT=1080`。
- **費用門檻**：每支影片上限 US$20、單筆超過 US$5 會跳出視窗請你再次同意（一次生成全部分鏡影片時一定會跳出）。
- **重試**：送出生成時帶 `Idempotency-Key`，網路錯誤或 5xx 以同一個鍵重試，不會重複生成；輪詢間隔 2 秒逐步增加到 10 秒，20 分鐘逾時。
- **生成結果**下載到 `app/data/media/gen/`（Higgsfield 的輸出網址只保留約 7 天）。
- **換模型**：用環境變數 `CLAUDE_MODEL`、`HIGGSFIELD_IMAGE_MODEL`、`HIGGSFIELD_VIDEO_MODEL` 覆寫，或在 Prompt Studio 把節點的 `target.model` 填成 Higgsfield 端點 ID（含 `/`）。影片模型是 Seedance 2.0 時會自動套用 `shot-video.json` 的 `seedance-2.0` 寫法規則。

## 語音合成

- 以 `TTS_PROVIDER` 選擇：`say`（macOS 內建台灣中文語音，免費、本機；在 macOS 上是預設）、`azure`（Azure 台灣中文神經語音，付費）、`local`（本機提示音；非 macOS 的預設）。
- 啟用 Azure：在 `.env` 加上 `TTS_PROVIDER=azure`、`AZURE_SPEECH_KEY`、`AZURE_SPEECH_REGION`（例如 `eastasia`）。費用約每百萬字 US$15（免費方案每月約 50 萬字），一支 30 秒影片的台詞約 100～150 字。
- 相同聲音與台詞只合成一次，檔案存在 `app/data/media/gen/`，重新合成成品不會重複付費。
- 「模型原生語音」模式下，角色台詞仍由 Seedance 產生並對口型，只有旁白走語音合成。

## 測試

自動化測試一律注入假的 Claude 用戶端與假的 `fetch`（`app/test/unit/real-providers.test.js`），不會呼叫真實服務、不花錢。
