# 接入真實 AI 服務

目前所有生成都走假實作（`AI_PROVIDER=fake`）。拿到金鑰與 API 文件後（見 `docs/BLOCKED.md` 第 1、2 項），依下列步驟接入，業務邏輯與既有測試都不用改。

1. 在 `app/src/ai/` 新增一個實作，例如 `higgsfield.js`，輸出與假實作相同的介面：
   - `name`、`models: { text, image, video, voice, music }`
   - `text.generate({ request, variables })` → `{ json, text, model, cost? }`
   - `image.generate({ request, refs, variant })` → `{ file, model, cost? }`（`refs` 是本機檔案路徑：去識別後的照片、定裝圖、分鏡圖）
   - `video.generate({ request, firstFrame, lastFrame, seconds, nativeVoice })` → `{ file, model, hasVoice, cost? }`
   - `voice.synthesize({ text, speaker })` → `{ file, seconds, model }`
   - `music.track(id, seconds)` → `{ file, model }`
   - 生成結果下載到 `mediaDir/gen/`，回傳本機路徑；回傳 `cost` 時以實際費用結算，否則以預估費用結算。
2. 金鑰從環境變數讀取（例如 `HIGGSFIELD_API_KEY`），不要寫進程式或 log。
3. 在 `app/src/ai/index.js` 的 `PROVIDERS` 註冊，例如 `higgsfield: createHiggsfieldProviders`；文字與圖片影片可以來自不同供應商，在 factory 裡組合即可。
4. 在 `app/test/unit/provider-contract.test.js` 的 `IMPLEMENTATIONS` 加上這個實作，並注入假的 `fetch`（回傳固定的 API 回應），確保測試不花錢。
5. 更新 `app/src/cost/prices.js` 的價格表，以及 `prompt-studio/prompts/` 圖片、影片節點的 `target.model`（例如 `seedance-2.0`，會自動套用 `modelRules` 的寫法規則）。
6. 啟動：`AI_PROVIDER=higgsfield node server.js`。
