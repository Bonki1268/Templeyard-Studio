## 總結

**完成了什麼**（24 步全部完成；步驟 23 已接入 Claude 與 Higgsfield）：
- 寺廟資料庫：982 筆清理為 940 間有效寺廟（紀年換算、電話正規化、里別補齊、廢止／未登記／財團法人／重名標記），支援臺／台混用與前綴的模糊搜尋。
- 完整 6 步流程（API + 網頁）：系列專案 → 新增影片（選寺廟、照片去識別、故事與 AI 潤飾）→ 故事腳本與分鏡 → 角色設計（版本鎖定、系列角色沿用）→ 精緻圖（分鏡膠捲逐格進度）→ 分鏡影片、合成（原生語音／語音合成、背景音樂、燒錄繁中字幕）、確認後下載 MP4。
- 每步確認紀錄內容版本；回頭修改時後續步驟標示「需重新確認」；被取代的版本保存在歷史中。
- 成本控管：預估 → 預留 → 結算，失敗退回；單筆超過門檻或累計超過上限需再次同意。
- 去識別：人臉與車牌自動遮蔽（本機 OpenCV 或假偵測器），可取消誤判（神像）或手動加框；原圖存在私有資料夾，沒有任何網址可取得；媒體以 1 小時短期網址存取。
- Prompt 沿用 prompt-studio 的指令檔與組裝（本機或 render API 兩種方式結果相同），已改為 16:9、補齊分鏡欄位、統一內容與宗教規則，並支援依模型的寫法規則（`modelRules`）；每筆生成紀錄記下 prompt id 與版本、模型、輸入、指令與成本。
- 測試：151 個 BDD 情境全部有對應測試；prompt-studio 8 項、app 單元與整合測試、32 項 Playwright 端對端測試，`bash scripts/gate.sh` 全部通過。全程使用假實作，不呼叫任何付費服務。

**怎麼啟動**：
```bash
cd app
npm install            # 只有開發用的 Playwright
node server.js         # 開啟 http://localhost:3000（預設 AI_PROVIDER=fake）
bash ../scripts/gate.sh  # 執行全部測試
```
需要本機 `ffmpeg`；有 `python3` + `opencv-python` 時自動使用 OpenCV 偵測人臉（可用 `DETECTOR=fake` 關閉）。資料存在 `app/data/`。Prompt 管理頁仍是 `cd prompt-studio && node server.js`（http://localhost:3300）。

**需要你決定的事**（詳見 `docs/BLOCKED.md`）：
1. ~~文字生成模型~~：已決定用 Claude，只需在 `.env` 填入金鑰。
2. ~~Higgsfield~~：已接入，只需在 `.env` 填入 `HF_API_KEY_ID`、`HF_API_KEY_SECRET`（見 `docs/真實服務接入.md`）。
3. ~~實際價格表、每支影片上限與單筆門檻~~：已決定，分鏡影片以 720p 生成，每支影片上限 US$20、單筆超過 US$5 需再次同意。
4. 去識別偵測器是否升級為深度學習模型（目前 OpenCV Haar，車牌偵測有限）。
5. 背景音樂來源（目前內建佔位音樂＋可上傳自己的音樂）。
6. 語音合成服務。
7. 15 秒影片與「8～12 格、每格 2～4 秒」的衝突（目前每格約 3 秒、4～12 格）。
8～10. 輸出解析度、短期網址時效、資料儲存方式（已採預設）。
11. 「對照原圖」是否要顯示原圖（目前不提供原圖網址，以遮蔽框對照）。
